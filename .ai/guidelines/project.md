# Project navigation

Read the repository-root `README.md` for setup and commands, `CODING_STANDARDS.md` for rules and enforcement limits, and `CONTEXT.md` for domain vocabulary. Use `docs/working-on-the-application.md` for the example map, common tasks, and source ownership. These are the canonical sources; do not copy their policies into generated agent instructions.

Keep project-authored workflows in `.ai/skills` and shared guidance in `.ai/guidelines`. Developer-selected Boost and agent configuration is personal and intentionally ignored. When `CONTRIBUTING.md` exists, read it before changing starter packaging, lifecycle scripts, or maintenance tests.
