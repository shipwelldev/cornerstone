## [v0.1.0](https://github.com/shipwelldev/cornerstone/releases/tag/v0.1.0) - 2026-07-26

* Introduce the opinionated Laravel 13 and Livewire 4 application foundation, including coding standards, setup and quality workflows, static analysis, and CI coverage.
* Add a tested expedition-planning vertical slice as the canonical application example, with a guided workflow for removing it once an application has its own vertical slice.
* Establish production-oriented application defaults for immutable dates, strict Eloquent models, passwords, destructive database commands, and HTTPS.
* Install the Cornerstone support package and lock the initial Composer and npm dependency baseline.
